# Smart Energy Consumption Prediction System
## Feature Engineering Module

### Objective
The purpose of this module is to create meaningful features from the cleaned energy consumption dataset to support forecasting, regression, clustering, anomaly detection, and peak demand prediction.

### Input Dataset

```text
data/processed/energy_clean.csv
```

### Features Created

#### Time-Based Features
- Datetime
- Hour
- Day
- Month
- DayOfWeek
- Week
- Quarter
- Weekend

#### Lag Features
- Lag_1
- Lag_24
- Lag_168

#### Rolling Features
- RollingMean_24
- RollingStd_24

#### Trend Features
- Difference
- PctChange

#### Peak Demand Feature
- Peak

### Data Validation
- Checked for missing values
- Removed rows containing invalid values generated by lag and rolling calculations
- Verified all engineered features

### Output Dataset

```text
data/processed/feature_engineered_dataset.csv
```

### Conclusion

Feature engineering was successfully completed by generating time-based, lag-based, rolling statistical, trend-based, and peak-related features. The resulting dataset is ready for use in forecasting, regression, anomaly detection, clustering, and peak prediction models.
